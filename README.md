# Md. Jahidul Islam — Personal Portfolio

A responsive, minimal and professional personal portfolio website using HTML, CSS, and JavaScript.

## Files
- `index.html` — website content
- `style.css` — layout, responsive styles, and colors
- `script.js` — mobile navigation and current year
- `.nojekyll` — helps GitHub Pages serve the site without Jekyll processing

## Before publishing
1. Replace the LinkedIn and GitHub placeholder links in `index.html` with your real profile URLs.
2. Replace `YOUR_EMAIL@example.com` with the email address you want to publish.
3. Review every academic detail and edit anything that needs correction.
4. Add your photo later if you want; the current design intentionally uses a typographic monogram instead.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `jahidul-portfolio`.
2. Upload all files in this folder to the repository root (not the ZIP file itself).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment to finish. Your URL will generally look like `https://YOUR-USERNAME.github.io/jahidul-portfolio/`.

GitHub Pages URLs depend on your actual GitHub username and repository name. This package does not publish the site automatically.
